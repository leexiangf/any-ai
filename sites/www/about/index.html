About Any AI

AI-AAII means Any Agent Install Index — a mall of community plugin directories for niche AI agent hosts.

What we are

Each host gets its own shop (subdomain) with a plugin market, categories, detail pages, and install guides. The root site aiaaii.com is the mall: brand, navigation, and shared policies.

What we are not

We are not Amp, Orca, Stably, Sourcegraph, or any other host vendor. We do not claim official status. Listings are community-sourced; verify before you install.

Data & trust

Entries link back to public sources. Detail pages are independent rewrites — not mirrored READMEs. Verified badges mean human review of listing quality, not a security audit of plugin code.
