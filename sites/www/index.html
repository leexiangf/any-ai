Any Agent Install Index

Any AI is the face. AI-AAII expands to Any Agent Install Index — the layer that collects, categorizes, and explains community extensions with installable commands.

We open shops for niche AI hosts with real heat and a thin official directory — not saturated mega-catalogs.

Say “Any AI.” Type aiaaii.com.

Why

Hosts ship the core. Indexes stay open.

Vendors build agents and CLIs — sometimes a thin official marketplace. Community plugins still need a place to be found and installed, with clear non-affiliation and source links.

That gap is the shop floor. When the next niche host qualifies, we open another subdomain.

FAQ

Questions

Is Any AI an official Amp, Orca, or Factory site?

No. This is a community project (AI-AAII). Each shop links back to upstream docs and sources. See About.

What does AAII stand for?

Any Agent Install Index. The domain aiaaii.com reads as AI-AAII.

Where do I browse plugins?

Open a host shop: amp.aiaaii.com, orca.aiaaii.com, or droid.aiaaii.com.

How do I list a plugin?

Use Submit. Listings must be public, have an install path, and must not impersonate official vendors.

Will you add more hosts?

Yes — when a host passes the open-shop bar. Niche over mass-market.
