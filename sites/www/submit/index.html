Submit a listing

Choose a market. We index public plugins with a clear install path.

Checklist

1. Pick a market: Amp, Orca, Droid, or Kimi.
2. Public source URL.
3. Working install instructions (e.g. amp plugins add … / /plugins install …).
4. Short one-liner; no official impersonation.

How to send

Open a GitHub Issue on leexiangf/any-ai using the Listing request template. Include market, source URL, install path, and a one-liner.
