Amp vs Orca vs Droid plugin install

Same job — extend the agent — three different install paths. Pick the market for the agent you already use, then follow that market’s command.

Any AI indexes each market separately. This page is only a selection guide: it does not replace upstream docs, and we are not affiliated with Amp, Orca, or Factory.

Quick compare

Agent Typical add / install Market
Amp amp plugins add … then reload / list amp.aiaaii.com
Orca Add a marketplace Git source, then install / pin a plugin orca.aiaaii.com
Droid (Factory) droid plugin marketplace add <git-url> then droid plugin install name@marketplace --scope user droid.aiaaii.com

When to use which market

  • Amp — you already run Amp and search for amp plugins add, modes, or contrib packs. Start at how to install an Amp plugin.
  • Orca — you need themes, languages, or a marketplace JSON to add under Settings → Plugins. Start at how to add a marketplace source.
  • Droid — you use Factory Droid and droid plugin CLI (native .factory-plugin or Claude-compatible marketplaces). Start at how to install a Droid plugin.

What stays the same

  • Public source + clear install path before we list.
  • Detail pages are independent rewrites, not mirrored READMEs.
  • Optional Listed on … badge after acceptance.

What differs

  • Amp leans on plugin files / amp plugins flows.
  • Orca leans on marketplace sources and editor contributions (themes, languages, VM recipes).
  • Droid leans on marketplace Git URLs + plugin@marketplace install ids (including Claude-compat manifests).
Can one plugin work on all three?

Rarely. Manifests and runtimes differ. List (and install) per market. Cross-port only when the author publishes an agent-specific package.

Where do I submit?

aiaaii.com/submit or the market Submit page. Pick the correct market in the listing request.
