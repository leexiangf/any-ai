Marketplace source vs plugin URL

  • Marketplace / index — a Git repo that lists many plugins (catalog JSON). Add once as a source.
  • Plugin URL — a single plugin repo. Often needs an explicit pin (#tag / #commit).

By host

  • Orca — Settings → Plugins → Marketplace sources; Install plugin wants #ref.
  • Amp — amp plugins add …
  • Droid — droid plugin marketplace add then droid plugin install
  • Kimi — /plugins install then often /new
