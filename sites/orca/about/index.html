About this market

A community directory of Orca plugins — with install paths when you need them.

orca.aiaaii.com is the Orca shop inside Any AI (AI-AAII) — a community install index, not an official marketplace and not a mirror of onorca.dev.

What we optimize for

  • Real marketplace Git sources and plugin #ref pins
  • Guides for hidden categories, reserved ids, and source errors
  • Honest visibility labels (in-app · web/#ref · retired · unknown) when evidenced
  • Unreviewed community code by default — you still read the repo

What we do not do

  • Compete with the official catalog on “most listings”
  • List repos that cannot install
  • Claim affiliation with Orca / Stably
