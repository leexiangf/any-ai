What is Orca?

Orca (Stably AI) is an ADE for running fleets of coding agents in parallel — Claude Code, Codex, Amp, and more — often each in its own git worktree. Plugins add languages, recipes, shortcuts, and (as the API grows) panels and workers.

Source: stablyai/orca · marketplace index: stablyai/orca-plugins

Install

Three steps

  1. Install Orca and enable the experimental Plugins feature in Settings.
  2. Add a marketplace source (Git URL + ref), or install a plugin repo pinned with #ref.
    Marketplace source example https://github.com/smwbev/orca-plugins.git
  3. Open All, pick a pack, confirm Install · then browse this market.

FAQ

Orca plugin questions

What is an Orca plugin?

A packaged extension (content pack, and over time panels/workers) described by orca-plugin.json, often distributed via a marketplace index. See the concept guide.

How do I add a community marketplace?

Settings → Plugins → Marketplace sources → paste the Git URL. Guide: Add marketplace source.

Is this the official Orca marketplace?

No. Official auto-seeded index is stablyai/orca-plugins. This site is a community web directory on Any AI (AI-AAII).

Why “experimental”?

Orca’s plugin system is marked experimental. APIs, visible categories, and install UX can change. Verify against current Orca docs before production use.

Can I use stablyai or orca- in my publisher id?

Those identities are reserved for the official marketplace. Using them incorrectly can invalidate an entire community index.

How do I get listed?

Submit a public plugin or marketplace repo with a pinable ref.

Part of Any AI?

Yes — mall at aiaaii.com; this subdomain is the Orca plugin market.

Marketplace URL vs plugin URL?

Marketplace sources take an index repo. “Install plugin” expects a plugin repo with an explicit #ref — don’t mix them up.

Why we exist

Orca ships a thin official index. We open the web layer.

Orca provides an experimental marketplace mechanism and a small official catalog. It does not run a full public SEO directory for community plugins. We collect, categorize, and document community packs and sources so people can find and install them.
