What is Orca?

Orca (Stably AI) is an ADE for running fleets of coding agents in parallel — often each in its own git worktree. Plugins add themes, editors, languages, panels, and recipes.

FAQ

Orca plugin questions

Is this the official Orca marketplace?

No. Official browsing/install UX lives in Orca and on onorca.dev. This site is a community web directory on Any AI (AI-AAII).

Plugin missing from All after install?

Check filters and hidden categories first: Themes / skills missing, then Plugin not showing.

Marketplace URL vs plugin URL?

Marketplace sources take an index repo. “Install plugin” expects a plugin repo with an explicit #ref. Guide: Add an explicit #ref.

Are community plugins reviewed?

Default status is unreviewed. We do not security-audit third-party code. Prefer pinned refs and read the GitHub source before enabling.

How do I get listed?

Submit a public plugin or marketplace repo with a pinable ref. We skip vague repos that cannot install.
