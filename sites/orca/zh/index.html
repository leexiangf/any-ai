Orca 是什么？

Orca（Stably AI）是并行跑多组编程助手的 ADE，常用各自的 git worktree。 插件可加主题、编辑器、语言、面板与配方。

官方入口
onorca.dev/plugins · stablyai/orca-plugins

常见问题

Orca 插件常见问题

这是官方 Orca 商店吗？

不是。官方浏览与安装在 Orca 应用和 onorca.dev。 本站是 Any AI（AI-AAII）上的社区网页目录。

装完在列表里找不到？

先看过滤与隐藏类目： 主题装了列表里没有， 再看 插件装了却不显示。

市场源地址和插件地址有何不同？

市场源用索引仓。「Install plugin」要的是单个插件仓并钉版本。 指南：提示要写版本号。

社区插件审核过吗？

默认未审核。我们不做第三方安全审计。优先钉版本，启用前请阅读 GitHub 源码。

如何上架？

提交公开、可钉版本的插件或市场索引。装不上的仓库我们不会收。
