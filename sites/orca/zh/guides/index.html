安装

什么是 Orca 插件主题、编辑器、面板等扩展包 如何打开插件功能先启用 Plugins 如何添加市场源在设置里粘贴 Git 地址 如何安装插件目录搜索，或按版本直装 如何更新插件刷新源，再升级已装包
