提示要写版本号

多半是把市场目录当成单个插件来装了。

Orca 的「安装插件」需要：单个插件仓库 + 明确版本。市场索引仓库不能直接贴进去。

  1. 如果是索引 / 目录仓库 → 改走 添加市场源。
  2. 如果是单个插件仓库 → 在地址后面加上 tag 或 commit：
    插件地址 + 版本 https://github.com/OWNER/PLUGIN.git#v1.0.0

怎么区分

  • 索引仓：根目录有 orca-marketplace.json → 加到市场源
  • 插件仓：有 orca-plugin.json → 安装时带上 #版本
