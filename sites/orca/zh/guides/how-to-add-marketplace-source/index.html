如何添加市场源

把索引仓库加进设置，不要贴进「安装插件」输入框。

  1. 打开 Settings → Plugins，确认已启用插件功能。
  2. 进入 Marketplace sources（管理源）。
  3. 粘贴索引仓库的 Git 地址（一般用默认分支即可）：
    市场源示例 https://github.com/stablyai/orca-plugins.git
  4. 源没有报错后，再到插件列表里搜索并安装具体插件。

如果提示要写版本号，多半是把索引仓库贴进了安装框。见 提示要写版本号。
