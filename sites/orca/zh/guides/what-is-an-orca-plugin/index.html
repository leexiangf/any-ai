什么是 Orca 插件

给 Orca 加主题、编辑器、语言、面板或配方的扩展包。

  1. 插件通常是一个 Git 仓库，里面有 orca-plugin.json；也可以出现在市场索引里。
  2. 常见类型：主题、图标、语法、自定义编辑器、侧栏面板、skills、虚拟机配方。
  3. 功能还在快速变化，安装前先看仓库说明和权限要求。
  4. 官方目录：onorca.dev/plugins。本站主要补充社区包怎么装。
