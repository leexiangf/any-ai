主题装了列表里没有

很多主题要在外观设置里选用，不一定出现在「全部」。

  1. 确认市场源正常，插件状态为已安装。
  2. 检查「全部 / 已安装」里的分类过滤。
  3. 主题请到 Appearance / 主题设置里直接选择。
  4. 还是没有 → 再看 装了却看不到。

有些主题可以网页直装，但不一定出现在端内「全部」列表，这不一定是没收录。
