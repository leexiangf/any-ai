如何安装插件

官方能搜到就直接装；否则加市场源，或按版本直装。

方式一：在 Orca 里搜索

  1. Settings → Plugins → 搜索插件名称 → Install。
  2. 也可以先在 onorca.dev/plugins 确认官方是否已有。

方式二：添加市场源

适合社区包。步骤见 如何添加市场源。

方式三：插件地址 + 版本

直装示例（必须带版本） https://github.com/OWNER/PLUGIN.git#v1.0.0

这里只能贴单个插件仓库，不要贴整个市场目录。
