名字因产品而异，意思差不多。

市场源和插件地址有什么不同

  • 市场源 / 索引：一个列出很多插件的仓库。在设置里添加一次即可。
  • 插件地址：某一个插件的仓库。直接安装时，通常要写上版本（#tag 或 #commit）。

各产品里怎么说

  • Orca：设置 → Plugins → Marketplace sources；装单个插件时要写版本。
  • Amp：amp plugins add …
  • Droid：先 droid plugin marketplace add，再 droid plugin install
  • Kimi：/plugins install，装完后常需要再执行 /new
