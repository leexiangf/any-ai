What is BPMN & DMN Modeler (Experimental)?

BPMN & DMN Modeler (Experimental) is an Orca plugin. Experimental. Open .bpmn and .dmn files as diagrams: view, simulate and lightly model BPMN processes and DMN decisions, and see an agent's changes to the file as they happen. No deployment, code links or Form editor yet. Use this listing to copy a real install path and open the upstream source — not as a substitute for the repository README. (Source)
