What it does

Provides a starter Multipass workspace lifecycle so agents can use short-lived VMs without inventing bootstrap scripts each time.

Compatibility

Orca with Plugins enabled; Multipass installed on the host when recipes run. Plugin system remains experimental — expect breaking changes.

Do I add this as a Marketplace source?

No — install the pack from the official index. Marketplace sources are for index repos like stablyai/orca-plugins.
