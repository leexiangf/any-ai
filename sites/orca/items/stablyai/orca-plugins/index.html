orca-plugins (official)

Canonical marketplace index — thin catalog, important format.

stablyai/orca-plugins is the official marketplace index Orca auto-seeds. It is a catalog of plugin Git URLs and pinned refs in orca-marketplace.json — not a warehouse of plugin binaries.

Usually pre-added in Orca https://github.com/stablyai/orca-plugins.git

Why list it here

So “orca marketplace” searches land on a structured page explaining the index format — while community sources remain discoverable beside it.

Can community indexes copy stablyai ids?

No — reserved identities can invalidate a whole community source.
