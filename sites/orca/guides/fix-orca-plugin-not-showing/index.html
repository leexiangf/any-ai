Plugin not showing after install

Source added or install succeeded, but All / Discover stays empty.

  1. Confirm Plugins is enabled: enable Orca plugins.
  2. Refresh the marketplace source row; clear last error if present.
  3. Confirm the index was added under Marketplace sources, not pasted into Install plugin (#ref fix).
  4. Open the pack JSON — publisher/id must match orca-plugin.json and avoid reserved stablyai / orca- ids.
  5. If themes or skills vanish from All, your build may hide those categories — see hidden categories.
