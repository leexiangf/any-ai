Add an explicit #ref

Orca rejected a Git URL because it looks like an index, not a single plugin pin.

You usually see this after pasting a marketplace repo into Install plugin. That field expects a plugin Git URL with an explicit commit/tag (#ref). Marketplace catalogs belong under Marketplace sources instead.

  1. Enable Plugins if the experimental feature is off.
  2. Open Settings → Plugins → Marketplace sources (Manage sources).
  3. Paste the index URL there (branch is fine; Orca pins a snapshot):
    Marketplace source https://github.com/smwbev/orca-plugins.git
  4. Wait until the source shows a pin / no error, then browse All and install a pack.
  5. Only use Install plugin when you have a single plugin repo and can append a real ref, e.g. …/orca-cobalt2-theme.git#v1.0.0.

How to tell index vs plugin

  • Index / marketplace → orca-marketplace.json (or catalog) at repo root → Marketplace sources.
  • Single plugin → orca-plugin.json → Install plugin with #tag or #commit.
