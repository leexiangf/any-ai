How to install an Orca plugin

From a marketplace listing or a pinned plugin repo.

  1. Prefer a marketplace: find the pack under All → Install → confirm consent/preview.
  2. Or install a plugin repository with an explicit pin:
    Patternhttps://github.com/owner/repo.git#v1.2.3
  3. Verify Installed tab shows the pack; test the feature (locale, shortcuts, etc.).

Success

Plugin listed as installed; behavior matches the author’s README.

If it fails

Card missing → category filtered in UI. Install fails → id/manifest mismatch or unsupported contribution kind.
