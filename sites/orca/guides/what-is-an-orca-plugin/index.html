What is an Orca plugin

Content packs and more — experimental extension units.

  1. A plugin is a Git-backed package with orca-plugin.json identity.
  2. Marketplaces are separate: orca-marketplace.json lists plugins + pinned refs.
  3. Types include content packs (languages, recipes, keybindings); panels/workers appear as the API matures.
  4. Treat the system as experimental — UI filters and schemas can change.
