Themes / skills missing from All

Marketplace lists packs, but theme or skill categories look empty.

Some Orca builds filter theme, icon, or skill categories in Discover/All even when the marketplace JSON lists them.

  1. Confirm Plugins is enabled.
  2. Refresh the marketplace source; open a pack and verify its declared type matches themes/skills/languages.
  3. Install from the pack detail when category chips are hidden — search by pack name if the UI allows.
  4. Upgrade Orca if your build notes mention experimental category filters.
  5. Community indexes must not use reserved ids — reserved plugin id.
