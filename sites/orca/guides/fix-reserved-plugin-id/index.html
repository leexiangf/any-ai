Reserved plugin id

Orca blocked a listing that uses a vendor-reserved publisher or id prefix.

Community marketplaces and plugins must not impersonate the host vendor. If the UI or install log mentions a reserved stablyai publisher or an orca- id, rename the identity in the manifest — do not try to “override” official packs.

  1. Open the failing pack’s orca-plugin.json (and any orca-marketplace.json entry that points at it).
  2. Change publisher to your GitHub owner (or org), not stablyai.
  3. Change id so it does not start with reserved orca- prefixes used by the product. Prefer yourname.plugin-slug style ids that match the listing.
  4. Commit, push, then refresh the marketplace source in Orca (or bump the pin) so the new manifest is fetched.
  5. Retry install from All. If the old id was already cached, remove the broken source and re-add it.

Why this exists

Reserved identities keep official Stably / Orca packs distinguishable from community indexes. Our directory also rejects impersonation on Submit.
