How to troubleshoot Orca plugins

Stable fix tree: #ref → source → reserved id → hidden category → not showing.

  1. Error mentions explicit #ref? → fix-add-an-explicit-ref
  2. Marketplace source row shows an error? → fix-marketplace-source-error
  3. Index rejected for stablyai / orca-? → fix-reserved-plugin-id
  4. Installed but themes/skills missing from All? → fix-orca-categories-hidden
  5. Still empty after a clean source? → fix-orca-plugin-not-showing

Error → guide URL

  • Add an explicit #ref → /guides/fix-add-an-explicit-ref/
  • Marketplace source failed → /guides/fix-marketplace-source-error/
  • Reserved publisher / id → /guides/fix-reserved-plugin-id/
  • Category hidden in All → /guides/fix-orca-categories-hidden/
