How to troubleshoot Orca plugins

Sources, pins, reserved ids, and hidden categories.

  1. Refresh the marketplace source; check last error on the source row.
  2. Confirm you added an index under Marketplace sources — not Install plugin.
  3. Open the JSON: publisher/id must match orca-plugin.json.
  4. Avoid stablyai / orca- reserved identities in community indexes — see reserved plugin id.
  5. If themes/skills vanish from All, Orca may filter those categories in your build.
