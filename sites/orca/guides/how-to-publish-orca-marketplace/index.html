How to publish an Orca marketplace

Ship orca-marketplace.json without reserved ids.

  1. Create a public Git repo with orca-marketplace.json.
  2. Set name, owner (must match hosting account), and plugins[] with id/source/ref.
  3. Pin each plugin to a tag or commit — avoid floating main for installs.
  4. Never use reserved publisher stablyai or ids starting with orca- unless you are official.
  5. Users add your repo URL as a Marketplace source; then Submit this market for indexing on orca.aiaaii.com.
