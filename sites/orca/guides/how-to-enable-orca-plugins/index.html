How to enable Orca plugins

Turn on the experimental Plugins feature first.

  1. Update Orca to a build that includes Plugins (experimental).
  2. Open Settings → Plugins and enable the plugin system / feature toggle.
  3. Confirm you see Installed / All (or Discover) and Marketplace sources.

Success

Plugins UI is visible; official marketplace source is present or addable.

If it fails

No Plugins menu → older build. Feature greyed out → check release notes for your OS.
