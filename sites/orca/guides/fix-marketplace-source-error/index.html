Marketplace source error

Source row shows an error after you paste a Git URL.

  1. Use a Git repository URL that contains a marketplace index (not a random single-file gist).
  2. Re-add under Settings → Plugins → Marketplace sources:
    Examplehttps://github.com/smwbev/orca-plugins.git
  3. If the host asks for a pin, use a tag or commit — see add marketplace source.
  4. Open the index JSON and confirm entries point at valid plugin packs.
  5. Reserved publisher/id failures → reserved plugin id.
