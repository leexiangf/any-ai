How to add a marketplace source

Indexes go in Marketplace sources — not Install plugin.

  1. Enable Plugins.
  2. Open Marketplace sources / Manage sources.
  3. Paste a Git URL and keep ref (often main):
    Examplehttps://github.com/smwbev/orca-plugins.git
  4. Add source → wait for snapshot pin → open All and install a pack.

Success

Source appears under Configured sources; listings show in All.

If it fails

“Add an explicit #ref” → dedicated fix (you used Install plugin with an index URL). Reserved id errors → reserved plugin id (stablyai / orca-).
