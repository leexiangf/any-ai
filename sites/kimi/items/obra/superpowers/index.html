What is superpowers?

superpowers is a library of agent skills plus bootstrap instructions that steer a coding agent into a disciplined build loop. Instead of jumping straight into code, the agent is nudged to clarify the goal, confirm a design you can actually read, produce an implementation plan, then run tasks with TDD and review. Skills are meant to trigger as mandatory workflows when relevant — not as optional tips. (Source)

Core capabilities

  • brainstorming — draw out intent and play back a design before code starts.
  • writing-plans / executing-plans — break work into small tasks with paths, verification, then execute inline or via subagents.
  • test-driven-development — enforce red → green → refactor; reject “code first, tests later.”
  • subagent-driven-development — dispatch per-task agents with review gates between steps.
  • systematic-debugging — a structured root-cause loop instead of random patches.
  • diagnosing-superpowers — inspect a session when skills misfire or burn unexpected tokens.

How to install and enable on Kimi Code

  1. Open the plugin manager and confirm you are in a Kimi Code session that supports /plugins.
    Open manager/plugins
    Expected: Installed / Official / Curated / Custom tabs appear.
  2. Prefer the Curated marketplace entry named Superpowers when shown; or install the public GitHub source directly.
    GitHub install /plugins install https://github.com/obra/superpowers
    Expected: the plugin appears under Installed (may prompt for third-party trust).
  3. Enable the plugin if it installed disabled. Kimi applies plugin changes on new sessions — start one after install or update.
    Fresh session/new
    Expected: skills from Superpowers are available in the new session.
  4. Verify with /plugins info superpowers (diagnostics + enabled). Acceptance check from upstream: ask for a small app (e.g. a React todo list) and expect brainstorming before code. Details: docs/README.kimi.md.

Typical usage

  1. Start a feature the way you normally would (“build X”). With Superpowers loaded, expect brainstorming / clarification before large code dumps.
  2. Approve the design chunks, then let the agent produce a plan with small tasks and verification steps — intervene if the plan skips tests.
  3. Say go and let subagent- or plan-driven execution run; use diagnosing-superpowers if skills stay silent or the agent ignores the plan (ask the agent to figure out what went wrong with Superpowers in this session).

Exact skill names and triggers evolve with the repo; treat the upstream “Basic Workflow” section as the source of truth.

When to use it — and caveats

Use Superpowers when you want process guardrails on non-trivial work (multi-file features, refactors, anything that needs a plan and tests). Skip it for one-line edits where brainstorming overhead is noise.

  • Multi-harness project: install Superpowers separately per agent (Kimi vs Claude vs Droid, etc.) — one install does not cover every CLI.
  • Third-party code: review the MIT-licensed repo before enabling MCP/hooks; this listing does not audit security.
  • Optional telemetry: upstream documents visual-companion logo loading; set SUPERPOWERS_DISABLE_TELEMETRY to opt out if you care.
Does Kimi Code list Superpowers in its default marketplace?

Yes — it is a Curated entry in Kimi’s default plugin marketplace. You can install from the Curated tab in /plugins, or pin the GitHub URL with /plugins install if you prefer an explicit source.

Why do Superpowers skills not show up after a Kimi install?

Start a fresh session with /new after install or update. Confirm /plugins info superpowers shows enabled; Kimi applies plugin changes to new sessions, so the old chat may keep missing skills.

Can I reuse one Superpowers install across Kimi and Claude Code?

No — install per harness. Upstream states installation differs by coding agent; if you use more than one, install Superpowers separately for each.

What should I do when Superpowers misfires mid-session on Kimi?

Ask the agent to diagnose Superpowers with session evidence. Upstream provides a diagnosing-superpowers skill that reads the transcript and can package a scrubbed bug-report bundle — better than guessing which skill failed.

Is this Kimi Plugin Market page the official Superpowers docs?

No — this is a community listing on Any AI. Install commands point at the public GitHub source; prefer the upstream README for authoritative skill lists and harness-specific notes.
