About this market

Community directory for Kimi Code plugins.

Kimi Plugin Market is a community-maintained install index on Any AI (AI-AAII). We list Official, Curated, and community plugins with real /plugins commands.

Data comes from the public Kimi marketplace JSON, GitHub manifests (kimi.plugin.json / .kimi-plugin/), and Submit requests. Detail pages are independent rewrites — not mirrored READMEs.

Not affiliated with Moonshot AI, Kimi, or any listed vendor. Prefer official docs for authoritative APIs.
