How to add a custom Kimi marketplace

Point /plugins marketplace at a JSON catalog URL.

Kimi accepts a custom marketplace JSON (version + plugins[] with id and source).

Browse custom catalog/plugins marketplace https://example.com/marketplace.json

Or set KIMI_CODE_PLUGIN_MARKETPLACE_URL to override the default catalog for the process.

Example community marketplace: compound-engineering.
