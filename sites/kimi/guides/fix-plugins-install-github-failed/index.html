/plugins install failed (GitHub)

HTTPS Git install returns an error or never finishes.

Use a real HTTPS repository URL — not a clone path and not an SSH remote.

  1. Retry with HTTPS:
    Install/plugins install https://github.com/OWNER/REPO
  2. If main is broken, pin a tag or commit:
    Pinned ref/plugins install https://github.com/OWNER/REPO/tree/v1.0.0
  3. Confirm the tree contains a Kimi plugin manifest at the documented path.
  4. Private repos need credentials the CLI can use; prefer a public release for install tests.
  5. After a successful install, apply with /reload or /new.
