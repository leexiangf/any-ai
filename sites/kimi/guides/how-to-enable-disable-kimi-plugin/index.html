Enable or disable a Kimi plugin

Toggle Installed plugins without uninstalling.

  1. Open /plugins and switch to the Installed tab.
  2. Select the plugin and toggle enable / disable (wording follows the current TUI).
  3. Apply the change:
    Reload/reload
    or start /new.
  4. Confirm skills appear (enabled) or disappear (disabled) in the new session.
  5. To remove entirely, uninstall from the same manager, then reload — see reload guide.
