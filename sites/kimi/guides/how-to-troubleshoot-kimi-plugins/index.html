Troubleshoot Kimi plugin installs

Missing skills, failed Git installs, and marketplace blanks.

  • Installed but no skills — run /reload; confirm the plugin is enabled in the Installed tab.
  • GitHub install fails — use an HTTPS repo URL; pin with /tree/<ref> or a release tag when HEAD is broken.
  • Empty Official/Curated — check network access to the default marketplace host; try /plugins marketplace without args.
  • Wrong manifest — Kimi looks for kimi.plugin.json or .kimi-plugin/plugin.json; Claude-only trees need a Kimi manifest.

Prefer upstream docs for API changes. This page is an independent community rewrite.
