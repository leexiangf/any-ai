What is a Kimi plugin?

Skills, agents, MCP, and hooks in one installable package.

A Kimi Code plugin is a directory or zip with a manifest at kimi.plugin.json or .kimi-plugin/plugin.json. It can bundle skills, agents, slash commands, hooks, system-prompt contributions, and MCP servers.

Official and Curated entries appear in /plugins. Community plugins usually install from a GitHub URL.
