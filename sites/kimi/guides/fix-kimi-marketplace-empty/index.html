Empty Official / Curated marketplace

Official or Curated tabs show no plugins.

Empty catalogs are usually network, catalog URL, or custom marketplace JSON — not a missing install command.

  1. Open the manager:
    TUI/plugins
  2. Inspect marketplace config:
    Marketplace/plugins marketplace
  3. If you added a custom catalog, verify the JSON URL returns a valid marketplace index (HTTPS, reachable).
  4. Remove a bad custom source, then re-add with how to add a marketplace.
  5. Still blank → see troubleshoot.
