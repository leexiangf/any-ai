How to install a Kimi plugin

Install from Official, Curated, or a GitHub URL.

  1. Open the manager:
    TUI/plugins
  2. Official / Curated: select an entry and press Enter.
  3. Or install a GitHub source directly:
    Install/plugins install https://github.com/obra/superpowers
  4. Run /reload or start a new session so skills and agents load.

Verify with /plugins list. Source: Kimi plugins docs.
