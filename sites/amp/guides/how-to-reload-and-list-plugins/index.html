How to reload and list plugins

Confirm Amp actually loaded what you installed.

Prerequisites: Amp running after an install or file change.

  1. Open the command palette (e.g. Ctrl+O) and run plugins: reload.
  2. Run plugins: list in the palette, or in a shell:
Shellamp plugins list

Success

Your plugin name appears; new tools/commands are available in the thread.

If it fails

Old code still runs → reload again or restart Amp. Missing from list → wrong directory or precedence overridden.
