amp plugins add failed

When the install command errors before the plugin appears in the list.

  1. Re-check the URL — it must be a public Git repo or a documented package the Amp CLI accepts.
  2. Clone or open the URL in a browser; 404 means the add will fail.
  3. Confirm you are signed in to Amp and the CLI version is current.
  4. Retry with a known-good listing from the directory.
  5. If add succeeds but nothing loads, see plugin not showing.
