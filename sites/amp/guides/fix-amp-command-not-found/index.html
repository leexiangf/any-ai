amp: command not found

The shell cannot find the Amp CLI — install it or fix PATH before amp plugins add.

Variants include amp: command not found, amp is not recognized (Windows), or a similar message when you run amp plugins add. This is a CLI / PATH problem, not a bad plugin URL.

  1. Confirm Amp is installed from the official Amp / Sourcegraph docs for your OS. App-only installs sometimes omit the shell binary.
  2. Open a new terminal and run:
    Checkamp --version
  3. If that fails, locate the binary (install directory or package manager path) and ensure it is on PATH. On Windows, restart the terminal after changing environment variables.
  4. Retry a known listing:
    Example amp plugins add https://github.com/lox/amp-autoresearch
  5. When the command runs but install fails, switch to amp plugins add failed.

Success

amp --version prints a version, and amp plugins list works in the same shell.
