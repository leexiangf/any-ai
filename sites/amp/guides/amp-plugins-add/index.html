amp plugins add

Primary CLI command to install an Amp plugin on your machine.

Use amp plugins add when you have a public plugin URL (GitHub repo or documented package). Prefer this over vague “import somehow” advice.

CLIamp plugins add <url-or-package>
Exampleamp plugins add https://github.com/ampcode/oracle
  1. Install and sign in to Amp so the amp CLI is available.
  2. Copy the install URL from the plugin’s listing or README.
  3. Run amp plugins add with that URL.
  4. Reload plugins (plugins: reload in the command palette) if the new tools do not appear.
  5. Confirm with amp plugins list.
