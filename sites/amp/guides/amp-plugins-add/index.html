amp plugins add

Primary CLI command to install a single-file Amp plugin from a URL or package id.

Searchers land here for the exact command word amp plugins add. Use it when you already have Amp’s CLI on PATH and a trusted install string from a listing or Amp docs — not as a substitute for “paste any GitHub repo.”

Command shape amp plugins add <url-or-package> amp plugins add <url-or-package> --target workspace amp plugins add --auto-update @amp/<name>

Amp documents URL add for single-file plugins available to projects on the machine; --target workspace writes into the current project’s .amp/plugins/ instead.

Shortest success path

  1. Confirm the CLI:
    Checkamp --version
    Missing? See amp: command not found.
  2. Copy an install string from the directory — example @amp/finder:
    CLI amp plugins add @amp/finder
  3. For project-local install:
    Project amp plugins add @amp/finder --target workspace
  4. Reload if the new tools do not appear: command palette Ctrl+O → plugins: reload.
  5. Verify:
    Verifyamp plugins list

What this command is for (and not)

amp plugins add is the shell path for installing a single-file plugin from a URL or package id Amp accepts. Many day-to-day “personal plugin” workflows instead paste a Share URL into a thread and ask Amp to import into personal plugins — that path is covered in How to install an Amp plugin.

Directory plugins (folder with index.ts) are often dropped into .amp/plugins/ or managed via personal/workspace repositories. Do not invent extra flags beyond what Amp documents for your version.

Useful variants

  • Machine-wide URL / package add

    Default amp plugins add … installs for all projects on the machine (Amp’s documented single-file URL flow). Use a public, fetchable target.

  • --target workspace

    Installs into the current project’s .amp/plugins/. Prefer this when the plugin should travel with the repo rather than your laptop profile.

  • --auto-update with @amp/… packages

    Amp publishes some installable packages (for example classic mode plugins) that accept --auto-update so Amp can keep them current. Drop the flag if you need a pin. Always copy the exact package id from Amp or from a listing you trust.

Failure branches

  • Command not found

    Shell PATH issue — follow amp: command not found.

  • Fetch / auth / invalid package

    Non-zero exit or missing list entry — follow amp plugins add failed.

  • Add ok, UI empty

    Reload and scope checks — installed but not showing.

Success criteria

  • The add command exits cleanly.
  • amp plugins list includes the plugin.
  • After reload, the plugin’s tools, commands, or modes appear where the author says they should.
