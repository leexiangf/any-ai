How to install an Amp plugin

Use the real CLI and Share URL flows Amp documents.

Prerequisites: Amp CLI or app signed in; plugin URL or file you trust.

Steps

  1. Pick a listing from the directory and open its source.
  2. Machine-wide single-file install:
    CLIamp plugins add <url>
    Add --target workspace for the current project’s .amp/plugins/.
  3. Or paste a Share URL into an Amp thread and ask to import into personal plugins.
  4. Or copy a .ts file into ~/.config/amp/plugins/ or .amp/plugins/.
  5. Reload and list — see reload guide.

Success

amp plugins list shows the plugin, or Amp confirms the import.

If it fails

Command not found → install Amp CLI. URL rejected → use raw/share URL Amp accepts. Silent no-op → reload plugins.
