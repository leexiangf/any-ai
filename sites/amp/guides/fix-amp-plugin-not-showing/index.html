Amp plugin installed but not showing

Install succeeded (or looked like it) — UI and tools still empty.

  1. Run amp plugins list — is the plugin present?
  2. If absent, re-run amp plugins add.
  3. If present, run plugins: reload.
  4. Restart Amp; check you are in the surface the plugin targets (CLI vs orb vs editor).
  5. Disable other plugins temporarily to rule out name collisions.
