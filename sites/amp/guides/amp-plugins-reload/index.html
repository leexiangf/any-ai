plugins: reload

Command-palette action to reload Amp plugins after install or local edits.

Search this when you just ran amp plugins add, dropped a file into .amp/plugins/, or edited a plugin and the current Amp session still behaves like the old code. This page is only about refreshing the running session. To inspect registration, use amp plugins list.

Palette action plugins: reload

Open the Amp command palette with Ctrl+O, type plugins: reload, run it. Sibling action: plugins: list for an in-product view.

Shortest success path

  1. Finish the install or save the plugin file you changed.
  2. In Amp, press Ctrl+O and run plugins: reload.
  3. Retry the plugin’s tool, command, or mode in the same thread (or a new one if the author requires it).
  4. Confirm with the shell when unsure:
    Verifyamp plugins list
  5. Still stale? Restart Amp once, then reload again. If the plugin never appears in list, the problem is install/scope — not reload.

When reload is the right tool

  • After amp plugins add when tools stay empty.
  • After editing .amp/plugins/*.ts or a directory plugin’s index.ts.
  • After Amp finishes a personal/workspace Share import and asks you to pick up changes.

Reload does not download updates by itself. For version bumps and import refresh, see how to update Amp plugins.

Failure branches

  • Nothing to reload (never installed)

    amp plugins list missing the name means add or file drop never registered. Fix via add failed or install — reload cannot invent a plugin.

  • Reload runs, UI still empty

    Wrong surface (looking for a mode when the plugin only registers a tool), precedence collision, or hosted-repo size limits. Follow not showing.

  • Old code still executes after edit

    You may be editing a non-winning copy. List the source path Amp loaded, edit that path, reload again. Restart Amp if the session cached a prior build.

  • Palette command missing

    Confirm you are in an Amp surface that exposes the command palette (Ctrl+O). Asking Amp in-thread to “reload plugins” is also documented by Amp as a valid path when the palette is awkward.

Success criteria

  • plugins: reload completes without an error toast.
  • New or edited tools / commands / modes become usable in the session.
  • amp plugins list still shows the plugin afterward.
