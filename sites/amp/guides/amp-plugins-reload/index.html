plugins: reload

Command-palette action to reload Amp plugins after install or edit.

  1. Open the Amp command palette.
  2. Run plugins: reload.
  3. Retry the plugin’s command or tool.
  4. If nothing changes, restart Amp, then run amp plugins list.

Pair with amp plugins add after every new install.
