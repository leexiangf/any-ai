How to troubleshoot Amp plugins

Hub: match the symptom, open the fix page — not another shallow checklist.

This page is the index for Amp plugin failures on this market. Start with the symptom map, jump to the dedicated guide, then come back only if you still need the generic isolation steps at the bottom. We keep fix detail on the linked pages so this hub stays navigable.

First two checks amp --version amp plugins list

If the CLI is missing, stop here and open command not found. If the CLI works, use the map below.

Symptom → guide map

  • amp: command not found Shell cannot find amp — install or PATH
  • amp plugins add failed Add errors: URL, auth, target, invalid package
  • Installed but not showing List may be OK; UI/tools/modes empty
  • amp plugins add Command-word install reference
  • How to install an Amp plugin CLI + Share URL + directory drop
  • plugins: reload Session still on old code after a good install
  • amp plugins list Need evidence of source and precedence
  • Reload and list Combined verify loop after install/edit
  • How to update Amp plugins Imports, update, --auto-update boundaries

Generic isolation (only after the map)

  1. Confirm scope: project .amp/plugins/, system config plugins dir, or personal/workspace repository import.
  2. Run amp plugins list and note precedence (project → system → personal → workspace).
  3. Run plugins: reload; restart Amp once if needed.
  4. Temporarily move other same-named plugins aside to rule out collisions.
  5. Re-read the listing / author docs for Amp version needs, env vars, or “new thread required” notes. Prefer a known package from the directory when bisecting.

Failure branches this hub does not invent

  • Syntax / runtime errors inside the plugin

    Fix the TypeScript/JavaScript the author shipped, or remove the plugin. This market does not mirror upstream source as the page body.

  • Untrusted code

    Plugins execute in your environment. If you cannot review the source, do not install — uninstall and pick another listing.

  • Wrong product surface

    Looking for a mode in the tool list (or the reverse) looks like a load failure. Match the author’s surface, then re-check not showing.

Success criteria

  • You landed on the symptom-specific guide that matches your error text.
  • amp plugins list shows a healthy registration for the plugin you care about.
  • After reload, the documented feature works in the Amp surface you use.
