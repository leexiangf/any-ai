How to troubleshoot Amp plugins

Isolate load path, precedence, and trust issues.

  1. Confirm the file path: project .amp/plugins/, system config dir, or personal/workspace repo.
  2. Run amp plugins list and note precedence (project → system → personal → workspace).
  3. Reload; if needed restart Amp.
  4. Temporarily move other plugins aside to rule out name collisions.
  5. Re-read the source README for env vars or Amp version needs.

Success

Plugin lists; behavior matches the author’s docs.

If it fails

Syntax errors → fix TS/JS. Wrong Amp surface (e.g. Puck) → plugins need orb/CLI/runner. Untrusted code → uninstall.
