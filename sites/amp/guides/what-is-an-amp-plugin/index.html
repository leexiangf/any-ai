What is an Amp plugin

TypeScript or JavaScript modules that extend Amp.

Prerequisites: Amp installed; optional familiarity with Node/TS.

Steps

  1. Know that plugins can register tools, commands, events, UI, skills, and AI helpers.
  2. Know scopes: personal, workspace, project (.amp/plugins/), system (~/.config/amp/plugins/).
  3. Treat plugins as code that runs on your machine — only load what you trust.

Success

You can explain plugin vs skill, and name at least two load locations.

If it fails

Confused with skills → read Amp docs on global plugins & skills. No files loading → check path spelling and reload.
