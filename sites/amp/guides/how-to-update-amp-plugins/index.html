How to update Amp plugins

Keep imports and CLI installs current without silent overwrites.

  1. For CLI installs, ask Amp to check imports or run:
CLIamp plugins update <name>
  1. For personal/workspace imports, ask Amp: “Check if any of my imported plugins are out of date.”
  2. Review the diff, then commit/push if you use hosted plugin repositories.
  3. Reload after updating files.

Success

Version or commit moves forward; plugin still lists cleanly.

If it fails

Conflicts on import → resolve manually in the plugin repo. Auto-update flags only apply where Amp documents them.
