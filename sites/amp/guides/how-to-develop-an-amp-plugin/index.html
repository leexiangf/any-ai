How to develop an Amp plugin

Author against Amp’s Plugin API, then list on this market.

  1. Read the Plugin API and kitchen-sink example.
  2. Create .amp/plugins/my-plugin.ts (or a folder with supporting files).
  3. Register only what you need: tools, commands, events, UI, skills.
  4. Reload and list; exercise the happy path.
  5. Publish a public repo or Share URL, then Submit to amp.aiaaii.com.

Success

Plugin loads locally; README states install and trust notes.

If it fails

API mismatch → check Amp version. Want distribution → use personal plugin repo / Share flow Amp documents.
