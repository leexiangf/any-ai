What is Amp?

Amp is a frontier coding agent for terminal, editor, and orbs. Plugins are TypeScript or JavaScript modules that add tools, commands, events, UI, and skills.

Source: Amp Docs — Plugins

Install

Three steps

  1. Install and sign in to Amp (amp CLI or app).
  2. Add a plugin:
    Primary amp plugins add <url>
    Or paste a Share URL into an Amp thread and ask to import it.
  3. Reload if needed (plugins: reload in the command palette) · then browse the market.

FAQ

Amp plugin questions

What is an Amp plugin?

A TypeScript or JavaScript module Amp loads to register tools, commands, events, UI, or skills. See What is an Amp plugin.

How do I install an Amp plugin?

Prefer amp plugins add <url> for machine-local installs, or import a Share URL in a thread. Guide: How to install.

Is this the official Amp marketplace?

No. This is a community index on Any AI (AI-AAII). Amp provides the plugin API and in-product sharing — not this public SEO directory.

Are listed plugins safe?

Plugins run code on your machine. Review the source repository before installing. “Verified” on this site means listing quality checks, not a security audit.

Where is the Amp documentation?

ampcode.com/docs/customize/plugins

How do I get listed?

Submit a public plugin with a clear install path.

What about Amp skills?

Skills are related but separate packages of instructions. This shop focuses on plugins; guides may cross-link skills where useful.
