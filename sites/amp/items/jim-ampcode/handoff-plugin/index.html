handoff-plugin

Command to hand off a long thread into a new Amp thread with a short goal.

Adds a Handoff · Start command: capture the current thread id, prompt for a short goal, call amp threads handoff, and open the new thread in a fresh terminal or browser.

curl mkdir -p ~/.config/amp/plugins && curl -fsSL https://raw.githubusercontent.com/jim-ampcode/handoff-plugin/main/handoff.ts -o ~/.config/amp/plugins/handoff.ts
Then Restart Amp — palette: Handoff · Start
