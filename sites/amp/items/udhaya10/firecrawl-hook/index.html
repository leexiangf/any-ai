firecrawl-hook

Global Amp hook replacing web tools with Firecrawl search/scrape.

Global tool.call hook that routes web_search / read_web_page through Firecrawl for every Amp mode and subagent. Also registers map/crawl/agent/browser tools. Affects the whole Amp process — review before installing.
