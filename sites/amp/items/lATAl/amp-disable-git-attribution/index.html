amp-disable-git-attribution

Turn off Amp thread and co-author lines in Git commits.

Sets amp.git.commit.ampThread.enabled and amp.git.commit.coauthor.enabled to false in Amp user settings when a thread starts. Does not change author, committer, signing, or unrelated settings.

Personal Plugin via Puck (Ctrl+/) Install https://github.com/lATAl/amp-disable-git-attribution as a Personal Plugin named amp-disable-git-attribution. Ask before pushing the Personal Plugins repository, then reload the plugins.
Local-only (no plugin) amp config edit # set both attribution settings to false
