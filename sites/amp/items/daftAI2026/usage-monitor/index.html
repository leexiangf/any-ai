What it does

Loads with the Amp CLI so you can track usage-oriented signals while chatting. After copy, start amp, then use plugins: list / plugins: reload from the Ctrl-o menu.

Compatibility

Amp CLI via binary install; Plugin API experimental and may break. Does not target the Amp editor extension.

Windows path?

Copy into %USERPROFILE%\.config\amp\plugins\usage-monitor.ts as documented upstream.
