@amp/oracle

Read-only review subagent as an oracle tool on a model you choose.

Official Amp plugin that exposes the oracle tool: a read-only subagent for code review and hard judgment calls. It never edits files. Pair it with @amp/finder and @amp/librarian — Oracle hands searches to those tools.

After install, run plugins: reload or restart Amp. Optionally edit MODEL / REASONING_EFFORT at the top of the plugin file.

CLI amp plugins add @amp/oracle
