Official Amp agent-mode plugins — reference and install source.

The official-plugins repository holds Amp’s official agent-mode plugins. Use it as a canonical reference for how modes are packaged, and as a source when Amp documents Share URLs or amp plugins add targets under @amp.

Example pattern from Amp docs amp plugins add --auto-update @amp/<plugin-name>

Role in this directory

We list it so “amp plugin” searches can land on a structured page with install vocabulary — not to replace Amp’s own Modes & Models UI.

Should I prefer Share URL or CLI?

Amp docs recommend personal import via Share URL when you want the plugin everywhere you use Amp. CLI amp plugins add fits machine-local installs. See install guide.
