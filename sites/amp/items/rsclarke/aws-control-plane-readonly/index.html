aws-control-plane-readonly

Guardrail plugin for AWS CLI — keep Amp on control-plane read-only calls.

This Amp plugin inspects AWS CLI commands before Amp runs them and allows only operations classified as control-plane read-only. Use it when you want Amp to explore AWS configuration without mutating resources.

Install (copy plugin into Amp plugins dir) # from https://github.com/rsclarke/amp-plugins — copy aws-control-plane-readonly.ts into ~/.config/amp/plugins/ then run plugins: reload
CLI pattern (when URL install applies) amp plugins add <raw-or-share-url>

What it does

Before Amp executes shell tooling against AWS, the plugin classifies the intended CLI invocation. Non read-only control-plane actions are blocked, reducing accidental writes during agent sessions.

Compatibility

Requires Amp with plugin loading enabled and AWS CLI available when used.

How do I reload after copying the file?

Open the command palette and run plugins: reload, or see Reload & list.
