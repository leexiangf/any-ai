read-x-post

read_x_post tool — X/Twitter status URLs to Markdown.

Registers a read_x_post tool that turns public X/Twitter status URLs into Markdown via x.pcstyle.dev. Expands reply chains by default; no X API key. Part of the pc-style/amp-plugins experiment suite.
