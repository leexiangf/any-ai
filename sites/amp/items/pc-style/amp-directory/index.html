amp-directory

Searchable community catalog for experimental Amp CLI plugins.

An independent Next.js + Convex catalog that browses, filters, and enriches experimental Amp CLI plugins (gists and small repos). This is a directory app, not an Amp runtime plugin — use it to discover sources, then install via Amp’s own flows.
