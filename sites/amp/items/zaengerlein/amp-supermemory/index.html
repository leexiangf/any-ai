amp-supermemory

Persistent memory for Amp via Supermemory — recall and capture across sessions.

Injects relevant memories and project knowledge at session start, and can capture conversations when a session ends. Requires a Supermemory API key or browser login. Wrap secrets in <private> tags to skip storage.

Global plugin file mkdir -p ~/.config/amp/plugins && curl -o ~/.config/amp/plugins/supermemory.ts https://raw.githubusercontent.com/zaengerlein/amp-supermemory/main/dist/supermemory.ts
Run with plugins PLUGINS=all amp

What it does

Auto-recall on the first message; auto-capture at session end. Login via palette Supermemory: Login or SUPERMEMORY_API_KEY.

Compatibility

Amp Plugin API experimental; manual install as documented upstream.

Project-only install?

Copy to .amp/plugins/supermemory.ts instead of the user config directory.

Is this official Amp?

No. Community plugin using a third-party memory service.
