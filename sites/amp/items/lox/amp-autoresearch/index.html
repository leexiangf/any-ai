amp-autoresearch

Autonomous optimization loop — edit, benchmark, keep or revert, repeat.

Turns Amp into a closed experiment loop: the agent edits code, runs a benchmark, logs the result, keeps improvements, and reverts failures until you stop it or hit a cap. Includes a browser dashboard and a status-bar scoreboard. Port of pi-autoresearch to Amp’s plugin API.

What it does

After Autoresearch: Start, Amp asks for a working directory and a one-sentence goal, then creates a branch, playbook, and baseline before looping hypotheses. Thread scoreboards and an SSE dashboard show metric deltas and ASI notes per run.

Compatibility

Requires Amp with plugins enabled. Installer targets ~/.config/amp/plugins/. Reload or restart Amp after install. Amp Plugin API is experimental.

How do I open the dashboard?

Use palette command Autoresearch: Dashboard, or click the status-bar scoreboard line during a session.

Is this an official Amp plugin?

No. Community-authored. This page is not affiliated with Amp.
