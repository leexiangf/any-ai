testmu-ai

Run, debug, and triage tests on the TestMu AI cloud via hosted MCP.

Plugin testmu-ai wires Droid to the TestMu AI / LambdaTest hosted MCP (mcp.lambdatest.com). Use it when you need cloud runs (HyperExecute), failure triage, SmartUI, accessibility, or Test Manager from the agent loop — plus Kane/Rook CLI skills packaged with the same marketplace.

Expect cloud credentials and account access; this is not a local-only skill pack.
