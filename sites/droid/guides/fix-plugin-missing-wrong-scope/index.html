Plugin missing (wrong scope)

Install succeeded, but list / the session does not show the plugin — user vs project scope mismatch.

This is not “not found @ marketplace.” The marketplace resolved and install returned OK; you are checking the other scope. Full background: --scope user vs project.

  1. Recall which scope you used on install. Default mental model: --scope user = machine-wide for your account; --scope project = this repo only.
  2. List both:
    Userdroid plugin list --scope user
    Projectdroid plugin list --scope project
    (Run the project command from the repo root where you installed.)
  3. If it appears under project but you expected it everywhere, reinstall with user scope (or keep project-only on purpose):
    User installdroid plugin install PLUGIN@MARKETPLACE --scope user
  4. Restart / reopen the Droid session after changing scope so the harness reloads the plugin set.
  5. If both lists are empty, go back to install errors: unknown marketplace, plugin not found, or still missing after update.

Success

The plugin id shows in the list for the scope you care about, and new sessions in that scope can invoke it.
