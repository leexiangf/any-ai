How to troubleshoot Droid plugins

Map the error text to a fix page, then retry the real CLI.

Unknown marketplace — run marketplace add first. Plugin not found — check plugin@marketplace id. Wrong scope — list user and project. Stale catalog — marketplace update then plugin update. Permission / private — Git auth before Droid can read the marketplace.

Error pages

  • Unknown marketplace
  • This doesn't appear to be a valid marketplace
  • Plugin not found @ marketplace
  • Still not found after marketplace update
  • Permission denied (private marketplace)
  • Plugin missing (wrong scope)
