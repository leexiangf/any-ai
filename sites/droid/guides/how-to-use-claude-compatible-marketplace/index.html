How to use Claude-compatible marketplaces

Droid falls back to .claude-plugin/marketplace.json.

Factory documents that a marketplace is read as .factory-plugin/marketplace.json first, then .claude-plugin/marketplace.json for Claude Code compatibility. Many community packs only ship the Claude path today.

  1. Confirm the Git repo has either manifest at the root (or under the documented path).
  2. Adddroid plugin marketplace add https://github.com/owner/repo
  3. Install with the marketplace id from the manifest name field:
    Exampledroid plugin install npmscan@npmscan --scope user
  4. If install fails, check droid plugin marketplace list for the registered id (sometimes derived from the repo slug) and retry.

Examples on this directory: TestMu AI (testmu-ai) and Cursor plugins (cursor-plugins).

Listings on this site marked Claude-compatible were verified to have a Claude marketplace manifest. They are not official Factory plugins — review source and permissions before install.
