Still not found after marketplace update

You ran marketplace update, but install still cannot resolve plugin@marketplace.

If droid plugin marketplace update finishes without error and droid plugin install name@marketplace still says not found, the catalog refresh worked — the id pair or upstream listing is wrong. This is narrower than the general plugin not found page.

  1. List registered marketplaces and copy the exact marketplace id Droid knows (often the JSON name, sometimes derived from the repo slug):
    Listdroid plugin marketplace list
  2. Open the live marketplace JSON on the default branch:
    • Native: .factory-plugin/marketplace.json
    • Claude-compat: .claude-plugin/marketplace.json — see compat guide
    Confirm the plugin’s name field matches what you type before the @.
  3. Force another refresh with the id from step 1, then install with that same marketplace id:
    Updatedroid plugin marketplace update MARKETPLACE_ID
    Installdroid plugin install PLUGIN@MARKETPLACE_ID --scope user
  4. If the plugin was renamed or removed upstream, update will succeed but the old id never returns — switch to the new name or pick another listing from the directory.
  5. Still failing with auth/clone errors during update → private / permission denied. Looking in the wrong scope after a successful install → wrong scope.

Quick checklist

  • plugin spelling matches JSON name (case-sensitive).
  • @marketplace matches marketplace list, not a guess from the GitHub org.
  • Default branch actually contains the marketplace file you think you updated.
