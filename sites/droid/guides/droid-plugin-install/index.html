droid plugin install

Install a plugin from a registered marketplace using plugin@marketplace.

CLIdroid plugin install droid-control@factory-plugins --scope user
Projectdroid plugin install droid-control@factory-plugins --scope project
  1. Ensure the marketplace is registered (marketplace add).
  2. Use the exact plugin@marketplace ids from the listing.
  3. Pick --scope user or --scope project.
  4. Verify with droid plugin list.

Errors: Unknown marketplace · plugin not found.
