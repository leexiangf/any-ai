droid plugin marketplace add

Register a Git marketplace before installing plugins.

Installs need a registered marketplace id. Add the source first.

CLIdroid plugin marketplace add https://github.com/Factory-AI/factory-plugins
Shorthanddroid plugin marketplace add Factory-AI/factory-plugins
  1. Copy a marketplace Git URL from a listing.
  2. Run droid plugin marketplace add.
  3. Confirm with droid plugin marketplace list.
  4. Install with droid plugin install.

Pin optional: append #tag or @<40-char-sha>. Claude-only manifests: compat guide.
