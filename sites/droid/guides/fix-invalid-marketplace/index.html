This doesn't appear to be a valid marketplace

marketplace add rejected the path or Git URL.

Droid expects a marketplace (catalog), not a lone plugin directory.

  1. Confirm the repo has .factory-plugin/marketplace.json (or Claude fallback .claude-plugin/marketplace.json) at the root.
  2. Do not point marketplace add at a single plugin folder — wrap it in a marketplace listing that plugin.
  3. Retry add on the marketplace root URL.
  4. Author path: publish a marketplace.
