How to publish a Droid marketplace

Shape .factory-plugin/marketplace.json for others to add.

Create a Git repo with .factory-plugin/marketplace.json listing plugins and sources. Ask others to run droid plugin marketplace add on your URL. See Factory building-plugins docs. Then Submit here.
