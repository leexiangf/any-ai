Permission denied (private marketplace)

marketplace add cannot clone the Git URL — auth, private repo, or a bad remote.

Typical messages include Permission denied, Authentication failed, could not read Username, or Repository not found while running droid plugin marketplace add. Droid never reaches the marketplace JSON if Git cannot fetch the repo.

  1. Open the URL in a browser while logged out (or a private window). If GitHub shows 404, the repo is private, renamed, or deleted — Droid will fail the same way without credentials.
  2. Prefer a public marketplace for personal installs. Community listings on this site assume a public Git source.
  3. If you must use a private org repo: configure Git credentials the same way your shell uses for git clone (SSH key loaded, or HTTPS credential helper / PAT with repo read). Then retry:
    Retrydroid plugin marketplace add https://github.com/OWNER/REPO
  4. Confirm the remote is the marketplace root (has .factory-plugin/marketplace.json or Claude fallback), not a random subfolder — wrong shape is a different error: valid marketplace.
  5. Corporate SSL / proxy intercepts can also look like auth failures; try the same URL with plain git ls-remote in the same terminal Droid uses.

Success

droid plugin marketplace list shows the new marketplace id, and install no longer dies at clone.
