Install

Three steps

  1. Install and sign in to Droid (Factory CLI or app).
  2. Add a marketplace:
    Primary droid plugin marketplace add https://github.com/Factory-AI/factory-plugins
  3. Install a plugin:
    Example droid plugin install droid-control@factory-plugins --scope user
    Then browse the market.

FAQ

Droid plugin questions

What is a Droid plugin?

A packaged set of skills, commands, droids, hooks, and MCP configs distributed via a Git marketplace. See What is a Droid plugin.

How do I install a Droid plugin?

Add a marketplace with droid plugin marketplace add, then droid plugin install name@marketplace. Guide: How to install.

Can I add Claude Code marketplaces?

Often yes. Droid reads .factory-plugin/marketplace.json first, then falls back to .claude-plugin/marketplace.json. Guide: Claude-compatible marketplaces.

Is this the official Factory marketplace?

No. This is a community index on Any AI (AI-AAII). Factory provides the plugin CLI and a thin official catalog — not this public SEO directory.

Are listed plugins safe?

Plugins run code on your machine. Review the source repository before installing. “Verified” on this site means listing quality checks, not a security audit.

Where is the Factory documentation?
